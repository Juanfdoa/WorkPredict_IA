#  Modelo de IA

Este repositorio contiene un modelo, junto con una interfaz gráfica web construida con **Flask** para realizar pruebas de forma sencilla.

---


## 🚀 Cómo usar este repositorio

### 1. Clonar el repositorio

```bash
git clone https://github.com/Juanfdoa/WorkPredict_IA
```

---

## 🧠 Entrenar el modelo

Si deseas continuar entrenando el modelo o entrenarlo desde cero, ejecuta:

```bash
python model.py
```

Este script se encargará de cargar los datos, entrenar el modelo y guardar los resultados. Puedes modificar los hiperparámetros directamente en el archivo `model.py` según tus necesidades.

---

## 🧪 Probar el modelo con la interfaz gráfica

Si ya tienes un modelo entrenado y quieres hacer pruebas de forma visual, ejecuta:

```bash
python app.py
```

Esto iniciará un servidor local con una interfaz web construida en **Flask**.
